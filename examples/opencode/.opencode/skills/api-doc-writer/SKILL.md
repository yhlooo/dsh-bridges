# API Doc Writer

Write endpoint documentation from the code in this repository. For each
public endpoint, document:

- method and path
- request parameters and body schema
- response shape and status codes
- one minimal usage example

Follow the conventions in `docs/tips/` (loaded as opencode `instructions`).
Keep the writing style consistent with `docs/tips/writing-style.md`.
