# Repository notes

General notes about this example repository, injected by the opencode bridge
because `opencode.jsonc` lists `docs/notes.md` in `instructions`.

- The example exercises: skills, command files, JSON commands, `AGENTS.md`
  memory, and globbed instruction files.
- opencode has no hooks file format — hooks are out of scope for this
  bridge, so there is no settings file here.
