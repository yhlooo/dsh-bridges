## 记录约定

- **命名**：`<日期>-<主题>.md`，日期取记录当天（`YYYY-MM-DD`），主题 kebab-case。
- **格式**：开头放元信息表（日期、参与者、状态、来源、相关文件）；正文按议题分节。
- **议题分节的三方结构**：
  1. 立场 / 批评（最初提出方的观点）；
  2. 回应（另一方立场）；
  3. 再反驳 / 补充（含**事实锚点**：引用代码路径、行号或文档原文，保证论点可验证）。
- **状态**：`待决策`（议题仍开放）、`已决策`（结论被采纳——采纳后行动项移入 `todo.md`，
  在条目注明来源讨论文件，并回填本文档的结论与采纳时间）、`已否决`。
- **记录忠实性**：双方论点都要保留，不因最终结论删改历史；结论单独标注，不改写原文。
- **语言**：中文；代码标识符、路径、命令保留英文原文。
- 一条讨论若产生新的待办（而非决策），仍只在讨论文件里列出候选方向并标"未采纳"，
  待明确拍板后再进 `todo.md`。
